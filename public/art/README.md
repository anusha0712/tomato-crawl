# Artwork slots

Drop files here and they appear automatically. No code change needed. When a
file is missing, the hand-drawn SVG plate is used instead, so the site is never
broken by an empty folder.

| File | Where it appears | Suggested size |
| --- | --- | --- |
| `hero.png` | Banner, bleeding off the right edge | ~1400 × 1000, transparent background |
| `stops/<stop-id>.png` | Card thumbnail | 400 × 400 square, transparent or cream |

Stop ids are the `id` field in `data/stops.ts`. Current ones:
